# [SafeLaunch AI] 원티드 AI Championship 2026 출품 서비스 기획서

## 1. 프로젝트 요약 (Executive Summary)
- **프로젝트 명**: SafeLaunch AI (세이프런치 AI)
- **부제**: AI 1인 창업가 및 인디 개발자를 위한 듀얼 소스(URL+README) 기반 실시간 컴플라이언스 백신
- **핵심 가치**: "코드는 완성되었지만, 법률 검토가 두려운 1인 빌더를 위한 단 10초 원클릭 법률 감사관"
- **대상 타깃**: 전 세계 1인 AI SaaS 빌더, 인디해커, 사이드 프로젝트 개발팀, 소규모 스타트업

## 2. 문제 정의 및 기획 배경 (Problem Definition)

### 2.1. 인디 개발 생태계의 숨겨진 지뢰: 규제 사각지대
최근 Vibe Coding, Cursor, LLM 프레임워크의 대중화로 누구나 단 며칠 만에 고품질 서비스를 배포할 수 있게 되었습니다. 하지만 **법률과 규제는 여전히 과거의 아날로그 방식에 머물러 있습니다.**

- **실제 사례 1 (위치정보법 위반)**: 사용자 주변 맛집/관광지를 추천하는 여행 AI 서비스를 론칭한 1인 개발자가 방송통신위원회에 '위치기반서비스사업자' 신고를 하지 않아, 방통위 실태조사 대상 통보를 받고 서비스를 강제 종료함.
- **실제 사례 2 (EU AI Act & 투명성 의무)**: 글로벌 사용자 대상 챗봇 SaaS를 론칭했으나 AI 생성물 워터마크 및 모델 고지를 누락하여 유럽 사용자 신고로 도메인 차단 경고를 받음.
- **실제 사례 3 (개인정보처리방침 및 푸터 고지 부재)**: 단순 랜딩페이지에 구글 애널리틱스(GA)와 결제 링크를 달아두었으나 개인정보처리방침이 없어 전자상거래법 및 개인정보보호법 위반 과태료 대상이 됨.

### 2.2. 기존 해결책의 치명적 한계
1. **전문 법무법인 / 변호사 자문**: 건당 최소 300~500만 원, 검토 소요 기간 2~3주. 빠른 MVP 가설 검증이 생명인 인디 프로젝트에 적용 불가능.
2. **단순 ChatGPT 프롬프트 질의**: 환각(Hallucination) 위험, 최신 한국 법령(2026년 개정안) 미반영, 실제 소스코드와 배포 화면의 유기적 연계 불가.
3. **엔터프라이즈 보안 솔루션 (Vanta, Drata)**: 연간 수천만 원의 비용, 대기업 ISMS/SOC2 인증 위주로 1인 웹서비스와 무관함.

## 3. 솔루션: SafeLaunch AI의 혁신적 접근법

### 3.1. 듀얼 소스 하이브리드 교차 감사 (Dual-Source Cross-Audit)
SafeLaunch AI는 **"배포된 웹 URL"**과 **"프로젝트 README.md"**를 한 공간에서 동시에 받아 교차 검증합니다:

```
[배포 웹 URL] ───> 경량 크롤러 ───┐
                                  ├──> [Gemini 3.6 Flash 교차 검증 엔진] ──> [3단 컴플라이언스 터미널]
[GitHub README] ──> 명세서 파서 ──┘
```

- **URL 단독 입력 시**: 배포 화면의 푸터, 약관 링크, 메타 태그, 외부 통신 내역을 라이브 점검.
- **README 단독 입력 시**: 배포 전 기획서 상의 API 목록, 데이터베이스 구조, LLM 호출 방식을 점검.
- **동시 입력 시 (하이브리드)**: 외부 표출 화면과 내부 로직을 상호 대조하여 **오탐(False Positive)을 완벽 차단**.

### 3.2. Seline Editorial 3단 터미널 아키텍처
한눈에 들어오는 직관적인 3단 화면으로 복잡한 법률 용어를 완벽하게 해체합니다:

1. **1단: Flagged Regulations (위반 법령 전수 리스트)**
   - 전체 / 국내법(🇰🇷) / 글로벌(🌐) 탭 즉시 전환
   - 각 법률별 위험도(CRITICAL, WARNING, CAUTION, PASSED) 색상 도트 표시
2. **2단: Problem Diagnosis (자연어 법률 대조 진단)**
   - 개발자가 이해하기 쉬운 **위반 사유(RISK)** vs **준수 기준(SAFE)** 2분할 대조
   - 실제 적발 시 예상되는 법정 과태료 및 제재 수위 투명 공개
3. **3단: Resolution & Compliance Gauge (준수율 & 1-Click 해결책)**
   - 실시간 100점 만점 원형 게이지
   - 즉시 복사하여 프로젝트에 붙여넣을 수 있는 표준 약관 및 면책 코드 스니펫 원클릭 제공
4. **회색지대(Grey Zone) 인터랙티브 핀셋 판별**
   - 아키텍처가 모호한 경우(예: 외부 LLM 호출 vs 결정론적 규칙 알고리즘) 1문 1답 인터랙티브 모달을 통해 사용자의 실제 시스템 구조를 확인 후 실시간 점수 재계산

## 6. 비즈니스 모델 및 성장 로드맵 (Business Model & Roadmap)

### 6.1. 비즈니스 모델 (Monetization Strategy)
1. **Freemium Self-Service (기본 무료)**
   - 기본 10대 규제 감사 및 웹 터미널 무제한 무료 제공 (원티드 생태계 기여)
2. **SafeLaunch Pro (구독형 SaaS)**
   - GitHub Action 연동: 코드를 push할 때마다 컴플라이언스 자동 점검 및 PR 코멘트
   - 규제 개정(2026 AI 기본법 시행 등) 실시간 도메인 재스캔 알림
3. **Legal Template Auto-Gen (문서 판매)**
   - 서비스 도메인 맞춤 3대 약관(이용약관, 개인정보처리방침, 위치정보약관) 1-Click 자동 생성 패키지

### 6.2. 향후 개발 로드맵
- **Phase 1 (현재 완료)**: 배포 URL + README 하이브리드 교차 검증 터미널 완성, 10대 법령 엔진 탑재.
- **Phase 2 (2026 Q4)**: GitHub App 출시 (PR 자동 컴플라이언스 리뷰), 원클릭 약관 다운로더.
- **Phase 3 (2027 Q1)**: 미국, 일본, 동남아 현지 법률 엔진 추가 탑재 (글로벌 론칭 전용 모드).
